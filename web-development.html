HTML & CSS

HTML and CSS are important technologies used to create and design websites. HTML provides the structure of a webpage while CSS controls its appearance and layout.

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure and content of web pages.

2. Common HTML Elements

  • <h1> - Creates a heading.
  • <p> - Creates a paragraph.
  • <a> - Creates a link.
  • <img> - Displays an image.
  • <ul> - Creates an unordered list.
  • <div> - Creates a container.
  • <form> - Creates a form.

3. Basic HTML Example

<h1>Welcome to My Website</h1>

<p>This is my personal website.</p>

<a href="about.html">About Me</a>

4. What is CSS?

CSS stands for Cascading Style Sheets. It is used to control the appearance, colors, fonts, spacing and layout of web pages.

5. Common CSS Properties

  • color - Changes text color.
  • background - Changes background.
  • font-size - Changes text size.
  • margin - Creates space outside an element.
  • padding - Creates space inside an element.
  • width - Controls element width.
  • height - Controls element height.

6. Basic CSS Example

body {
    background: #f5f7fb;
}

h1 {
    color: #2563eb;
    font-size: 40px;
}

7. Difference Between HTML and CSS

  • HTML: Creates the structure and content of a webpage.
  • CSS: Controls the design and appearance of a webpage.

8. Importance of HTML & CSS

  • Used to create websites.
  • HTML organizes webpage content.
  • CSS improves website appearance.
  • CSS helps create responsive layouts.
  • They are fundamental technologies for web development.

9. Website Development

A simple website can be created by combining HTML and CSS. JavaScript can also be added to make the website interactive and dynamic.
